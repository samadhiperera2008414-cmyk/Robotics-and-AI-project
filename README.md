# Robotics and AI Project: Maze Solver Visualizer

A Python-based maze generation and pathfinding visualizer comparing search algorithms including Breadth-First Search (BFS) and Depth-First Search (DFS).

---

## Features

- **Recursive Backtracker Maze Generator:** Generates a perfect maze with exactly one valid path between any two points.
- **BFS Solver:** Finds the shortest path while exploring nodes level-by-level.
- **DFS Solver:** Explores deeper path branches first, demonstrating differences in total nodes explored vs path efficiency.
- **Terminal Visualization:** Displays the generated maze, solution path, path length, and total nodes explored directly in the console.
